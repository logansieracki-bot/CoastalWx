# Map assets

Coastline/land/lake/border/state geometry, cropped to the Atlantic/US basin
and coordinate-rounded from a prior project's world-extent GeoJSON (itself
derived from the GSHHS/Basemap boundary datasets). Plain WGS84 lon/lat,
no projection applied — the editor uses raw lon/-lat as SVG coordinates
directly and controls the "camera" via the SVG viewBox.
